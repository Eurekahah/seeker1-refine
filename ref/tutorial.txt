1.   概况
 ● 摄像头：4鱼眼摄像头，全局快门，1088x1280@20fps，灰度，fov：206x206，摄像头曝光同步
   （硬件同步触发，精度是ns级别），AE同步。
 ● IMU：200HZ
 ● 编码：MJPEG硬件编码
 ● 功耗：<10W 电压12V，支持到3S电池。
 ● 屏幕：接上HDMI屏幕，然后当成电脑使用即可。

3.   通信
  seekser模块可以使用usb和wifi和主机进行通信方便调试。其中usb可以同时使用adb和rndis。需
要先接上电源，等待差不多10s以上再接USB线，这个问题后续会解决。
3.1.   adb
 adb shell
    默认进入root模式并且是sh，可以在里面运行bash或者login root。密码为1，如果密码不正确，用
adb shell然后passwd修改密码。
                                                            4
如果出现错误：
 error: insufficient permissions for device: user in plugdev group; are your udev rules wrong?
 See [http://developer.android.com/tools/device.html] for more information
表明当前用户不在plugdev组，可以：
  a. 运行：
 sudo adb shell
  b. 或者：
 sudo bash -c 'echo SUBSYSTEM==\"usb\",ATTRS{idVendor}==\"2207\",\
 MODE=\"0666\",GROUP=\"plugdev\",SYMLINK+=\"android\",\
 SYMLINK+=\"android_adb\" >> /etc/udev/rules.d/90-android.rules'
  c. 或者：
 sudo usermod -a -G plugdev $(whoami)
建议用方法 b或c 然后重新连接USB即可。
3.2.   RNDIS（USB网络）
    rndis即usb网络，使用iperf进行速度测试可以达到0.5Gbps，seeker omni模块的IP地址为
10.42.0.2，因此usb网络连接PC需要配置如下：
3.2.1.   ubuntu配置
    seeker模块的网络配置路径在：/etc/network/interfaces.d/usb0
 allow-hotplug usb0
 iface usb0 inet static
 address 10.42.0.2
 netmask 255.255.255.0
 gatway 0.0.0.0
 dns-nameservers 8.8.8.8
    即板子的usb网络ip地址为10.42.0.2，pc上面可以配置ip地址为10.42.0.1使用。
将seeker模块上电，和PC之间使用USB连接，稍等一会大约11s后，PC打开Settings，在USB Ethernet
右侧点击设置
