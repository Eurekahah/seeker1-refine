# A4 重新标定最简流程

本文只保留重新标定所需的最少步骤。默认使用：

- 标定板：`F:\Code\Seeker1\calib\board\Seeker1_Charuco_A4_26mm.pdf`
- 板参数：`/data/local/tmp/board_A4_26mm.json`
- 采集目录：`/data/local/tmp/calib_data_a4`
- 标定输出：`/tmp/calib_out_a4`

## 0. 打印和固定标定板

- PDF 必须按 **100% / 实际大小** 打印，不能选“适合页面”。
- 打印后用尺子量底部 `100 mm` 校验条，误差应小于 1 mm。
- 也可以量整块板：横向 7 格 = 182 mm，纵向 5 格 = 130 mm。
- A4 纸必须贴在硬质平板（泡沫板、亚克力、木板）上，再把硬板固定到墙上。
- 不要只用胶带贴四个角，纸面中间鼓起或翘曲会直接污染外参。
- 板面到相机建议 0.3–0.5 m，最远不要超过 0.6 m。

## 1. 启动环境

在 Windows PowerShell 中：

```powershell
cd F:\Code\Seeker1
docker start seeker1
.\docker\start-adb-host.cmd
docker exec seeker1 adb devices
```

应看到设备状态为 `device`。

启动四路相机：

```powershell
docker exec seeker1 adb shell 'bash -lc "screen -wipe >/dev/null 2>&1; screen -dmS cam /data/local/tmp/start_cam.sh"'
```

## 2. 打开 A4 四宫格预览

```powershell
docker exec seeker1 adb shell 'bash -lc "screen -S preview -X quit >/dev/null 2>&1 || true; screen -wipe >/dev/null 2>&1; screen -dmS preview bash -c \"/data/local/tmp/run_preview.sh --board-spec /data/local/tmp/board_A4_26mm.json --port 8090 > /tmp/preview.log 2>&1\""'
```

浏览器打开：

```text
http://localhost:8090
```

页面显示四路画面、每路角点数和 `OK / PARTIAL / NO BOARD`。标定板进入画面后，角点数应稳定在 10 以上。

停止预览：

```powershell
docker exec seeker1 adb shell 'bash -lc "screen -S preview -X quit"'
```

## 3. 采集

开始新的采集（会清空上一次的 A4 采集目录）：

```powershell
docker exec seeker1 adb shell 'bash -lc "rm -rf /data/local/tmp/calib_data_a4; rm -f /data/local/tmp/stop_capture; screen -S cap -X quit >/dev/null 2>&1 || true; screen -wipe >/dev/null 2>&1; screen -dmS cap bash -c \"/data/local/tmp/run_assisted.sh --board-spec /data/local/tmp/board_A4_26mm.json --out /data/local/tmp/calib_data_a4 --target-cam 45 --target-pair 18 > /tmp/capture_a4.log 2>&1\""'
```

实时看进度：

```powershell
docker exec seeker1 adb shell 'tail -f /tmp/capture_a4.log'
```

看到类似下面的进度就说明在正常保存：

```text
PROG saved=12 left:8/45 right:9/45 bright:7/45 bleft:6/45 left-right:5/18 right-bright:4/18 bright-bleft:3/18
```

达到目标后会自动停止。也可以手动停止：

```powershell
docker exec seeker1 adb shell 'bash -lc "touch /data/local/tmp/stop_capture; sleep 1; screen -S cap -X quit >/dev/null 2>&1 || true"'
```

## 4. 标定

把图片拉回容器并运行标定：

```powershell
docker exec seeker1 adb pull /data/local/tmp/calib_data_a4 /tmp/calib_data_a4
docker cp F:\Code\Seeker1\calib\scripts\calibrate_fisheye.py seeker1:/tmp/
docker cp F:\Code\Seeker1\calib\board\board_A4_26mm.json seeker1:/tmp/
docker exec seeker1 bash -lc "rm -rf /tmp/calib_out_a4; python3 /tmp/calibrate_fisheye.py --data /tmp/calib_data_a4 --board-spec /tmp/board_A4_26mm.json --out-dir /tmp/calib_out_a4 --max-views 100"
```

把结果复制回 Windows：

```powershell
docker cp seeker1:/tmp/calib_out_a4/kalibr_cam_chain.yaml F:\Code\Seeker1\calib\kalibr_cam_chain_a4.yaml
docker cp seeker1:/tmp/calib_out_a4/calibration_report.json F:\Code\Seeker1\calib\calibration_report_a4.json
```

重点检查报告里的：

- `cameras.<cam>.omni.median_reproj_px`：单路中位重投影误差，目标小于 1 px。
- `cameras.<cam>.used`：每路实际使用的视图数，A4 建议至少 35。
- `pairs.<a>-<b>.rms`：相邻外参重投影误差。
- `pairs.<a>-<b>.translation_norm_m`：基线长度，A4 重新标定后应仍在 0.07 m 左右。
- `pairs.<a>-<b>.rotation_deg`：相邻光轴夹角，应接近 90°。

## 5. 部署新标定文件

```powershell
docker cp F:\Code\Seeker1\calib\kalibr_cam_chain_a4.yaml seeker1:/tmp/kalibr_cam_chain.yaml
docker exec seeker1 adb push /tmp/kalibr_cam_chain.yaml /data/local/tmp/kalibr_cam_chain.yaml
```

注意：在全景节点确认稳定之前，不要删除旧的 `kalibr_cam_chain.yaml`。新文件先单独保存为 `kalibr_cam_chain_a4.yaml`，验证后再覆盖板端文件。
